# Evaluation Data

> [!NOTE]
> Korean version: [ai-model-eval.README.kr.md](../../docs/localization/ai-model-eval.README.kr.md)

This directory contains evaluation datasets for retrieval, near-miss tagging, and rule input extraction.

## Files

| File | Purpose |
|---|---|
| `retrieval_law_v0.jsonl` | Law retrieval evaluation queries |
| `near_miss_tag_v1.json` | Near-miss tagging evaluation cases |
| `rule_input_extract_v2.json` | Rule input extraction evaluation cases |

## Validation

Run the relevant validation or evaluation script under `scripts/` before changing a baseline dataset.
